# Pizza-Sales-Analysis-PowerBI
Interactive Pizza Sales Analysis Dashboard built using Power BI to analyze revenue, orders, pizza sales, customer preferences, and best/worst performing products.

## 📌 Project Overview

This project is an interactive Pizza Sales Analysis Dashboard developed using Microsoft Power BI.

The dashboard analyzes pizza sales performance, revenue, orders, customer preferences, and product-level performance to provide meaningful business insights.

## 🎯 Project Objective

The objective of this project is to:

- Analyze overall pizza sales performance
- Track revenue and order metrics
- Identify sales trends by day and month
- Analyze sales by pizza category and size
- Identify best-selling pizzas
- Identify underperforming pizzas
- Support data-driven business decisions

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📊 Key KPIs

- Total Revenue
- Average Order Value
- Total Pizza Sold
- Total Orders
- Average Pizza Per Order

## 📈 Dashboard Features

### Sales Overview

- Daily Trend for Total Orders
- Monthly Trend for Total Orders
- Sales by Pizza Category
- Sales by Pizza Size
- Total Pizza Sold by Category

### Best & Worst Sellers

- Top 5 Pizzas by Revenue
- Top 5 Pizzas by Quantity
- Top 5 Pizzas by Total Orders
- Bottom 5 Pizzas by Revenue
- Bottom 5 Pizzas by Quantity
- Bottom 5 Pizzas by Total Orders

## 🔍 Key Insights

- Identified the highest-performing pizza categories.
- Analyzed sales performance across different pizza sizes.
- Identified the best-selling pizzas based on revenue, quantity, and orders.
- Identified low-performing pizzas requiring further business attention.
- Analyzed daily and monthly ordering patterns.
